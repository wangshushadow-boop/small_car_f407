# C30D V2.2 当前引脚占用

本文只记录当前 `small_car_f407.ioc` 中已经配置的引脚占用。

## 系统与调试

| 引脚 | 当前配置 | 用途 |
| --- | --- | --- |
| PH0 | RCC_OSC_IN | HSE 外部晶振输入 |
| PH1 | RCC_OSC_OUT | HSE 外部晶振输出 |
| PA13 | SWDIO | SWD 调试/下载 |
| PA14 | SWCLK | SWD 调试/下载 |

## 串口与 USB

| 引脚 | 当前配置 | 用途 |
| --- | --- | --- |
| PA9 | USART1_TX | 调试串口发送 |
| PA10 | USART1_RX | 调试串口接收 |
| PA11 | USB_OTG_FS_DM | USB Host DM |
| PA12 | USB_OTG_FS_DP | USB Host DP |

## I2C

| 引脚 | 当前配置 | 用途 |
| --- | --- | --- |
| PB10 | I2C2_SCL | OLED 时钟 |
| PB11 | I2C2_SDA | OLED 数据 |

## 超声波 / 雷达接口

当前 `.ioc` 已使用板载 `N10 雷达接口` 预留超声波：

| 接口 | 引脚 | 推荐配置 | 用途 |
| --- | --- | --- | --- |
| N10 | PC12 | GPIO_Output | 超声 TRIG |
| N10 | PD2 | GPIO_EXTI2 | 超声 ECHO |
| N10 | 5V | 电源 | 超声 VCC |
| N10 | GND | 地 | 超声 GND |

## 舵机 PWM

| 引脚 | 当前配置 | 用途 |
| --- | --- | --- |
| PC8 | TIM8_CH3 | 舵机 1 PWM |
| PC9 | TIM8_CH4 | 舵机 2 PWM |

## 当前外设配置摘要

| 外设 | 当前用途 |
| --- | --- |
| FreeRTOS | CMSIS-RTOS2 默认任务 |
| TIM1 / TIM9 / TIM10 / TIM11 | 电机 PWM |
| TIM2 / TIM3 / TIM4 / TIM5 | 电机编码器 |
| TIM8 | 两路舵机 PWM |
| USART1 | 串口调试与命令 |
| USB_OTG_FS | USB Host 手柄 |
| I2C2 | OLED 模块 |
| PC12 / PD2 | 超声波 TRIG / ECHO |
