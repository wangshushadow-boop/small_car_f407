## 调试下载

STM32F407 常用 SWD 下载/调试连接如下：

| ST-Link | STM32F407 |
| --- | --- |
| SWDIO | PA13 |
| SWCLK | PA14 |
| GND | GND |
| 3.3V / VTref | 3.3V |
| NRST | NRST |

说明：

- `GND` 必须共地。
- `3.3V / VTref` 用于目标板电压检测，不建议用 ST-Link 给整车供电。
- `NRST` 建议接上，方便复位连接。
