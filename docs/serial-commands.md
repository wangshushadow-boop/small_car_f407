# 串口命令说明

本文档记录当前工程已经实现的串口调试命令。

## 串口参数

- 串口：USART1
- 引脚：PA9 为 TX，PA10 为 RX
- 波特率：115200
- 数据位：8
- 停止位：1
- 校验位：无
- 发送格式：文本模式，建议命令末尾带换行 `\r\n`

## 设计说明

所有模块默认正常运行，串口命令只控制是否把对应模块的数据打印到串口，不会关闭模块本身。

默认所有模块数据打印关闭。需要查看哪个模块，就手动发送对应的 `on` 命令；查看完再发送 `off`。

## 命令列表

| 命令 | 作用 |
| --- | --- |
| `imu on` | 打开 IMU 数据打印 |
| `imu off` | 关闭 IMU 数据打印 |
| `pad on` | 打开手柄数据打印 |
| `pad off` | 关闭手柄数据打印 |
| `servo on` | 打开舵机输出打印 |
| `servo off` | 关闭舵机输出打印 |
| `motor on` | 打开电机输出打印 |
| `motor off` | 关闭电机输出打印 |
| `ultra on` | 打开超声波距离打印 |
| `ultra off` | 关闭超声波距离打印 |
| `status` | 查看当前打印开关状态 |
| `help` | 显示命令帮助 |
| `?` | 同 `help` |

## 示例

打开手柄打印：

```text
pad on
```

关闭手柄打印：

```text
pad off
```

查看当前状态：

```text
status
```

## 注意事项

- 命令需要在串口助手中以文本模式发送。
- 当前固件支持接收空闲自动执行命令；如果串口助手支持发送换行，仍建议打开换行发送。
- 默认关闭的是串口打印，不是模块功能。
